# 全软件重设计审计（2026-10-17）

> 背景：句法卡重做的成功经验 = **数据契约保持、呈现层重造、把"脑补的对应关系"变成"直接可感的交互"**。
> 本文件盘点全软件还有哪些同类机会。每条标注优先级与移植归属（common 可直接被 Linux/macOS 复用）。
> 实施纪律：**做完即 commit**（与 desktop-port 会话共享工作树，提交只暂存自己改的文件）。

## P1 词条页结构化（词典的核心体验）★common

**现状**：`VocabIndex.english()` 返回的 gloss 是一坨字符串（`n. 1. 抛弃 2. …`），
侧栏「词条」页整段铺出来。而库里躺着 **GlossParser（按词性切义项）+ WordNet 42,514 义项组**
这套现成资产——典型的"启发式很烂但数据在库"。

**重设计**：
- 词头行：词 + 音标 + **发音按钮**（TTS，安卓 TextToSpeech；抽象成 `interface Speaker`，
  桌面端给空实现或调系统 `say`/`speech-dispatcher`——移植时只补实现不动物 UI）；
- **按词性分段**：名词区/动词区/形容词区，每段内义项**编号列表**（1. 2. 3.），
  义项行可点 → 复制该义项 / 用该义项追问；
- 考纲星级（vocab2 的 level 列）画成小星；
- 考纲标签 chips（六级/雅思/托福/GRE）。

## P2 生词本可见化（收藏闭环）★common

**现状**：收藏词存进 prefs 但**没有任何界面能看到它们**——收藏即失踪。

**重设计**：词条页顶部「已收藏 (N)」区块：横向流式 chips，点 chip 直达词条；
长按/chip 右侧 × 取消收藏。纯 Compose，零平台依赖。

## P3 同文本超链接的悬停预览 ★common（桌面优先）

**现状**：链接点了才知道去哪——去错了还得折返。

**重设计**：桌面指针悬停 300ms → 链接上方弹 mini 预览卡：
分支标题 + 该分支最后一条回复的前两行 + 更新时间；点击才真正跳。
弹层用 Compose `Popup`（common 可用）；数据来自
`ConversationDao`（节点 + 末条回复摘要，需一个轻量只读查询——查询不算改表，纪律允许）。
触屏长按同语义。**"链接可预知"是全软件最欠的直观性之一。**

## P4 页内查找命中可视化（正文路径）★common

**现状**：Ctrl+F 只有 "n/m 处" 计数；OCR 路径有词框高亮，**正文路径命中不上色、不跳转**。

**重设计**：命中词复用生词那套投影通道（`projectSourceRanges`）画琥珀底；
"当前命中"加亮为深琥珀，上一处/下一处按钮驱动；命中变化时自动滚动该行入视。
低成本、高感知。

## P5 翻译小窗双语逐句对照 ★common

**现状**：原文一坨在上、译文流式一坨在下，对照全靠眼疾。

**重设计**：契约升级成**对齐对**模式：模型返回
`[{"src":"原句","dst":"译文"}]`（复用句法卡的严格 JSON + 失败回退机制：
解析失败退回现在的整段流式，不阻塞）。渲染成交织行：原句浅灰小字、译文正文行，
行间细分隔线。读外文文献的核心体验升级，比"整段翻"直观一个量级。

## P6 对话气泡的桌面级快捷动作（chat 侧）

**现状**：操作藏在选择工具条/长按里。

**重设计**：桌面指针悬停气泡 → 气泡角上浮出三枚小圆钮（复制/引用/针对此回复开分支），
点击即用；触屏不变。common（Popup + 悬停检测纯 Compose）。

## P7 树形导图画布（大工程，建议移植后做）

导图画布的交互深度依赖指针（悬停/右键/滚轮缩放），桌面端才是它舒展的环境。
候选：焦点节点"聚光灯"模式（点节点 → 非邻接压暗）、滚轮缩放 + 空格拖移（对齐桌面惯例）。
**放到 desktop-port M4 之后**，避免与移植改碰撞。

## 不动的

- OCR 选词/水滴手柄/纸张手势：刚磨平，别碰。
- 书架：刚修完。
- 阅读器正文页的手势分流：同理。

## 实施顺序建议

P2（半小时级）→ P1（词条页主体）→ P4 → P3 → P5 → P6；P7 独立排期。
每条做完：编译双 flavor + commit + 随下次发版交付。
