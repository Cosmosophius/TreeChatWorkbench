# TreeChat 交接增量（v1.24.0 全量完成：Word 式浮动提问栏 + 25dp 水滴手柄 + 48dp 热区 + 选区定位修复）

> 写于 2026-10-12 11:12。

---

## 1. 本轮关键交互飞跃与修复

### 一、彻底解决「提问栏死板固定在最底下」—— 升级为 Word 式就地浮动操作栏
- **实现组件**：`FloatingSelectionToolbar`
- **定位机制**：
  - 基于当前选区的包围矩形 `controller.selectionBoundingRect()`；
  - 包装在 Compose 原生 `Popup` 中，动态计算：水平方向居中对齐在选区正中央，垂直方向**紧贴选区正上方 10dp 处**；
  - 若文字贴近屏幕顶端视口，代码自动翻转悬浮在选区正下方；
  - **不仅在主干对话中生效，在工作台缩放的悬浮小窗内选字，也原地在文字上方弹出！**

---

### 二、手柄全面升级为 Google AOSP 官方 25dp 标准与 48dp 触控热区
- **旧实现硬伤**：`HANDLE_RADIUS = 9f`（仅 2~3dp），`HANDLE_TOUCH_SLOP = 22f`（仅 7~8dp），如米粒般极难点中；
- **新实现对齐官方规范**：
  - `HANDLE_RADIUS = 36f`（直径约 25dp，高清晰水滴游标形态，带半透明高光阴影）；
  - 外层包裹 `48.dp` 规范化无形触控热区，手指一碰即中，拖拽调整极度跟手。

---

### 三、高亮取消与撤销完善
- 选区与已有高亮只要有交集，浮动操作栏即智能显示为「取消高亮」；
- 操作栏新增「撤销高亮」操作项。
